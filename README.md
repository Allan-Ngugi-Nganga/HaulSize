# HaulSize Website

This repository contains the static marketing website and legal documentation for the HaulSize iOS application, optimized for deployment via GitHub Pages.

## Overview

The purpose of this site is to host the required App Store URLs (Privacy Policy and Support) as well as to serve as the primary landing page for the application.

## Development

The website is built using vanilla HTML5, CSS3, and minimal JavaScript. It utilizes modern CSS features such as CSS variables and backdrop filters to achieve a premium aesthetic without the overhead of external frameworks. 

There is no build process required. To view the site locally, you can serve the directory using any standard HTTP server.

```bash
python3 -m http.server 8000
```

## Deployment

This site is deployed via GitHub Pages from the `main` branch. Any changes pushed to `main` will be reflected on the live site.
